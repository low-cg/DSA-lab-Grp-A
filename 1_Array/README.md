# Array — Finding Average

This program calculates the **average of elements in an array** using dynamic memory allocation in C.

## 📌 Description

The program first takes the number of elements from the user and dynamically allocates memory for the array using `malloc()`.

Then, it takes the array elements as input, calculates their sum, and finds the average.

Finally, the dynamically allocated memory is released using `free()`.

## 🧠 Concepts Used

* Array
* Dynamic Memory Allocation
* `malloc()`
* Pointer
* Loop
* `free()`
* Basic arithmetic operations

## ⚙️ How It Works

1. The user enters the number of elements.
2. Memory is dynamically allocated for the array.
3. The user enters the array elements.
4. The program calculates the sum of all elements.
5. The average is calculated.
6. The allocated memory is freed.

## 💻 Example

### Input

```text
Enter number of elements: 5
Enter elements: 10 20 30 40 50
```

### Output

```text
Average is: 30
```

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
